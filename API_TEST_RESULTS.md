## 3. Smart Receipt Ingestion API

### 3.1 Parse Messy Receipt Text (Uber Taxi)
> [!NOTE]
> Tokenizes raw receipt text into structured merchant, amount, category, and date with confidence score.

**Request**:
```http
POST /receipts/parse HTTP/1.1
Host: localhost:8080
Accept: application/json
X-User-Id: 4
X-Role: STAFF
Content-Type: application/json

{
  "receiptText": "UBER Airport Ride 450 INR 14 Aug 2026"
}
```

**Response**: `HTTP/1.1 200 `
```json
{
  "merchant": "Uber",
  "amount": 450,
  "expenseDate": "2026-08-14",
  "category": "TAXI",
  "confidence": 95,
  "rawText": "UBER Airport Ride 450 INR 14 Aug 2026"
}
```
